# motion-lancamento

Skill do Codex para criar o pacote visual de lançamento de música autoral ou cover: capa, flyer de pré-save, thumb do YouTube, Motion Data, Motion Pré-save e dois cortes de Reels.

## Instalação em outro chat

Peça ao Codex:

> Instale a skill `motion-lancamento` deste repositório: https://github.com/Maaaneeel/motion-lancamento-skill/tree/main/motion-lancamento

Ou execute o instalador de skills:

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo Maaaneeel/motion-lancamento-skill \
  --path motion-lancamento
```

A skill ficará disponível a partir do turno seguinte e poderá ser chamada como `$motion-lancamento`.

## Pacotes padrão

### Lançamento autoral

- Capa para plataformas — 3000 × 3000
- Flyer de Pré-save — 1080 × 1920
- Thumb do YouTube — 1280 × 720
- Motion Data — 1080 × 1920
- Motion Pré-save — 1080 × 1920
- Corte de Reels 1 — 1080 × 1920
- Corte de Reels 2 — 1080 × 1920

### Cover

- Capa — 3000 × 3000
- Thumb do YouTube — 1280 × 720
- Motion Data — 1080 × 1920
- Corte de Reels 1 — 1080 × 1920
- Corte de Reels 2 — 1080 × 1920

O diretório `motion-lancamento/assets` contém as marcas e referências visuais. As instruções completas estão em `motion-lancamento/SKILL.md`.
